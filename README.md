# Taskly — Todo List Web App

A clean, modern todo list web app built with plain HTML, CSS, and vanilla JavaScript.
Tasks are saved in the browser using `localStorage`, so they persist across page refreshes.

## 🔗 Live Demo
**[https://nandani1512.github.io/synent-task5-todoapp-Nandani/](https://nandani1512.github.io/synent-task5-todoapp-Nandani/)**

## ✨ Features
- Add a task (click **+** or press **Enter**)
- Mark a task as completed
- Delete a task
- Tasks persist between sessions (localStorage)
- **Today's Progress** bar with a live completion percentage
- **Dark / light mode** toggle (remembered across visits)
- **Confetti** burst when you complete a task
- A full-screen **celebration** when all tasks are done
- Responsive design — works on mobile and desktop

## 🎨 Design
- Coral Sunrise color palette (soft coral & pink)
- Sora + Inter fonts
- Smooth animations and micro-interactions throughout

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript (vanilla — no frameworks or build tools)

## ▶️ How to Run Locally
No installation needed. Just open `index.html` in any web browser.

## 📁 Project Structure
- `index.html` — page markup
- `style.css` — styling, theme, and animations
- `script.js` — application logic (tasks, persistence, theme, confetti)
